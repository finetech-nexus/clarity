# Dépréciations

Clarity 0.1.0 ne déprécie aucune route native : la version est initiale.

Côté amont, Clarity n'annonce pas de dépréciation à la place de Marble ou de Ballerine. Les fichiers historiques `public_api.yaml` et `v1_public_api.yaml` sont archivés et ne sont pas servis. Le contrôleur de stockage externe Ballerine est marqué déprécié dans son propre code et n'est pas repris.
